This package provides a full simulation environment for the UFACTORY xArm5 robot arm running on ROS2 Jazzy and Gazebo Harmonic (Ubuntu 24.04). The simulation uses gz_ros2_control with MoveIt2 for motion planning and includes a keyboard teleoperation node for real-time joint control. The workspace includes the UFACTORY vendor packages (xarm_ros2, xarm_python_sdk) patched for Jazzy compatibility — no additional cloning required.

What it does: Launching the main file brings up Gazebo with a table environment, spawns the xArm5 with its gripper end effector, starts the ros2_control joint trajectory controllers, and opens RViz2 with the MoveIt2 Motion Planning plugin. A second terminal runs the keyboard controller, which lets you drive each of the 5 joints and the gripper independently using key presses, with adjustable step sizes.

Prerequisites: Ubuntu 24.04, ROS2 Jazzy (ros-jazzy-desktop, python3-colcon-common-extensions), Gazebo Harmonic with ROS bridge (ros-jazzy-ros-gz-sim, ros-jazzy-ros-gz-bridge, ros-jazzy-gz-ros2-control), and MoveIt2 (ros-jazzy-moveit, ros-jazzy-moveit-py, ros-jazzy-xacro). See src/xarm5_gz_control/INSTRUCTIONS.md for the full setup walkthrough including build steps and workspace sourcing.
